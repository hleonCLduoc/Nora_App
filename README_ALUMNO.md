## Alumno
1. Descomprime el ZIP.
2. Abre esta carpeta en Android Studio.
3. Ejecuta Sync Project with Gradle Files.
4. Espera que finalice la sincronización.
5. Ejecuta la aplicación.

No modifiques `settings.gradle.kts` ni `gradle/wrapper/gradle-wrapper.properties` durante la clase.
